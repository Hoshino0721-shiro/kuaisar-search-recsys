## 优先级

1. **更可信分组 + TopK 排序目标**：从同用户、完全相同的分发时间戳构造曝光组，对照 BCE、普通 pairwise、LightGBM LambdaRank 和神经 LambdaLoss。原固定 100 万训练曝光的只读可行性检查得到 107385 个可用近似批次、126812 对、14824 用户、235164 个不同曝光端点；没有重训。官方说明系统可能同批分发多物品，但不能据相同时间戳恢复真实 request/slate 或反馈先后。后续考虑按组采样，避免随机抽行破坏组完整性，并与采样匹配的 BCE 对照。
2. **召回先验与精排对齐**：保留 RRF 的来源、名次、近期热度等信号，先对照固定排名融合，再研究有限纠偏或残差排序。训练期召回图和热度必须严格早于目标，不能将训练末索引回填历史样本。提高历史日志重合不等于提高无偏兴趣相关性。
3. **内容增强的双通道兴趣模型**：物品 ID 回退作者/类目及匿名 caption token；推荐与搜索历史分路，用候选相关 DIN 激活及门控融合。先量化覆盖，不预设 attention 可以解决 89% 搜索历史 UNK。query 与 caption 共享匿名词 ID，可以训练共享表示，但这些整数不是可直接送进中文预训练模型的自然语言。
4. **粗精排联合优化/蒸馏**：在合法训练期候选分布上，让粗排同时学习曝光和精排教师信号，检查教师 Top20 保留、观察正例保留与成本。教师分数是软监督，不是真实点击标签；不能仅靠蒸馏解决弱教师或池外召回问题。

DCN-V2 可作为同输入架构对照，但不自动补足信息；HSTU/生成式推荐可作为后续研究分支，不作为当前瓶颈的保证解。新版双塔仍只完成真实数据准备和工程入口，尚无真实训练结果。缺少可靠曝光概率，不将热门度重加权称为 IPS 无偏学习。

在训练部分构造滚动时间开发回测，每个窗口重新拟合词表/状态/模型，不复用包含未来记录的全量模型。训练内滚动回测不是新的独立最终测试；旧测试仍不用于反复选型。

## 原增强缓存的数据契约问题

[官方字段说明](https://kuaisar.github.io/detailed_statistics.html) 明确作者 ID `0` 为 padding。当前增强缓存构造器将 raw author 0 当作普通作者值，这与字段契约不符，需要在新缓存中区分缺失/PAD/UNK，并单独重训消融；不能悄悄修改旧缓存或重写历史结果。

只读核查：该 token 在固定训练样本出现 3062/1000000 次（0.3062%），验证出现 2031/725753 次（约 0.2798%）。目前没有证据它是整体收益有限的主因，数值 A 模型不使用作者字段。尚未实施修正，也没有据此声称改进效果。

更新：原增强缓存与上述历史指标未改动；新表示实验缓存已将 raw author 0 映射 PAD，并独立核验全部对应物品。新训练还增加了全量样本、内容表示和实际输入覆盖管理，不是单独只改 PAD 的消融，不能将全部收益归给该修正。
