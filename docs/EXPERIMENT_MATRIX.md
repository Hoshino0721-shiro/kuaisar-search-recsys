# 实验矩阵

所有实验必须记录数据版本、切分方式、随机种子、负采样方式、候选集版本和模型配置。

2026-10-21 精排开发优先级更新：先按 [DCN 特征增强计划](DCN_FEATURE_PLAN.md) 在相同 DCN 框架上完成统计基线、容量对照、属性 embedding、身份 embedding 的实验，再研究推荐/搜索历史及 attention。下方保留整体研究矩阵，不代表各项已经实现或获得收益；当前不在本机训练。

## 召回实验

| 编号 | 召回方式 | 主要参数 | 指标 |
|---|---|---|---|
| R0 | 热门召回 | 时间窗口、场景 | Recall@K、Coverage |
| R1 | ItemCF | 相似度、邻居数 | Recall@K、长尾覆盖 |
| R2 | 双塔召回 | embedding 维度、负样本数 | Recall@K、P95 延迟 |
| R3 | 多路融合 | 各路配额或权重 | Recall@K、Coverage、延迟 |

## 精排实验

| 编号 | 模型 | 目标 | 指标 |
|---|---|---|---|
| P0 | LR/MLP | 概率基线 | AUC、GAUC、LogLoss |
| P1 | DeepFM 或 DCN | 特征交互 | AUC、GAUC、NDCG |
| P2 | DIN | 序列兴趣 | GAUC、NDCG、校准 |
| P3 | 双通道兴趣模型 | 搜索短期 + 推荐长期 | 分组指标、消融 |

## 必做消融

| 消融 | 要回答的问题 |
|---|---|
| 去掉搜索通道 | 搜索行为是否提供额外信息 |
| 搜索与推荐直接拼接 | 双通道结构是否比简单融合更好 |
| 去掉门控 | 门控是否在场景切换时有效 |
| 去掉时间衰减 | 短期行为是否需要时间权重 |
| 去掉 hard negative | 难负样本是否提升排序能力 |
