# 简历可直接使用版

## 基于 KuaiSAR 的多路召回与表示学习推荐系统

技术栈：Python / PyTorch / NumPy / SciPy / SQLite

- 基于约 1066 万条搜索与推荐交互构建离线实验系统，完成数据审计、全局时间切分与历史前缀特征构建，分别评测推荐曝光点击预测和搜索会话排序，控制未来信息泄漏。
- 实现分块构图、TopK 邻居截断与内存映射的 ItemCF 索引，融合近期热门与个性化召回；在固定 2000 候选预算下，开发验证 Recall@2000 由 9.4229% 提升至 9.7700%，支持不可变版本与 SHA256 校验。
- 在约 575 万条真实推荐曝光上训练 DCN，融合用户/物品 ID、作者、类目及匿名 caption 词向量；三随机种子对照中，内容增强相对 ID/属性模型的开发 AUC 从 0.71985 提升至 0.72235，用户 GAUC 从 0.61990 提升至 0.62301。
- 实现 64 维属性/历史双塔、批内对比学习与分块全库检索，完成多种子及严格时间前缀复核；配套验证选轮、学习率调度、完整轮断点恢复与独立指标重算，142 项回归测试通过。

## 使用边界

以上为简历正文建议，按版面可压缩或选取三条。1066 万为原始交互规模，575 万为推荐训练曝光量；指标全部是离线开发验证，不是线上 CTR、生产收益或新的盲测成绩。

Recall 对照是近期热门与热门＋ItemCF 的固定预算对照。AUC/GAUC 对照是匹配训练协议的 ID/属性与内容增强，不是拿不同容量的数值模型做纯单因素归因。

双塔已真实训练和验收，但加入现有 RRF 后没有通过候选净增量与 Top20 稳定性条件，因此未成为默认。不要写“双塔显著提升全链路效果”“已部署 FAISS/ANN”或“工业级线上系统”。新版检索是冻结用户快照上的精确检索；caption 为匿名词 ID，不是预训练中文语义向量。
