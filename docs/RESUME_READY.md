# 项目描述：搜推算法岗

## 项目经历

### KuaiSAR 多路召回与内容增强推荐系统

技术栈：Python / PyTorch / NumPy / SciPy / SQLite

项目背景：基于约1066万条搜索与推荐交互构建离线实验系统，完成多路召回、曝光点击预测与候选排序对照。

- **召回优化与索引：** 针对稀疏共现噪声，引入共同用户支持度约束，构建分块TopK邻居索引与内存映射查询；支持度消融中纯ItemCF Recall@1000由3.47%提升至4.01%（相对+15.7%），融合近期热门后，固定2000候选的开发Recall@2000由热门基线9.42%提升至9.77%。
- **内容精排建模：** 在575万条真实曝光上训练DCN，联合用户/物品ID、作者、类目与匿名caption词向量补充物品内容信息，开发AUC达到0.7223、用户GAUC达到0.6230；通过特征消融及固定候选评测，区分曝光预测与最终列表收益。
- **历史双塔召回：** 基于286万次正点击训练64维属性/历史双塔，以最近30条去重推荐点击均值增强用户表示，采用批内对比学习与95万物品的分块精确检索；历史组纯Recall@1000由属性组1.30%提升至1.79%，结合新增/挤出命中与时间回放验收融合效果，保留RRF作为默认。

## 指标说明

- 1066万为原始搜推交互规模，575万为推荐训练曝光量，95万为训练点击物品库；都不是线上服务规模。
- 9.42%→9.77%比较近期热门与近期热门＋改进ItemCF，使用同一开发日、物品库、用户和2000候选预算。支持度单因素实验的纯CF Recall@1000为3.4665%→4.0107%；不能把所有融合增益单独归给支持度阈值。
- 正文AUC/GAUC为内容组的三个种子均值，精确值0.722349/0.623011。匹配宽度、数据与训练协议的ID/属性对照为0.719850/0.619901；保留该对照供追问，不用绝对指标回避比较。内容收益属于曝光预测，尚未转化为超过RRF的Top20覆盖。
- 1.30%→1.79%比较属性双塔与增加推荐历史的双塔，使用各自选定检查点的主窗口纯召回指标。加入融合后Recall@2000为9.3326%，低于原9.7700%；Top20种子方向不一致，因此未采用双塔路。
- 所有新增指标均为离线开发验证或历史日期回溯，不是线上CTR、生产收益或新的盲测成绩。新版检索为冻结用户快照上的分块精确点积；caption是匿名词ID，不是预训练中文语义向量。
