# KuaiSAR 项目 v2 结项报告

日期：2026-10-22。8 个真实双塔模型、两时间窗口评测、142 项测试及全量独立审计已通过，本项目按约定范围结项。定位为传统搜推算法与可复现实验工程，不是生产系统或线上 A/B 项目。后续 LLM 推荐另立项目，不继续扩大本项目模型范围。

## 1. 最终保留什么

默认仍为 **近期热门 Top2000＋改进 ItemCF Top1000 → 等权 RRF → 2000 候选 → 前 20**。双塔、LR/DCN、pairwise、embedding/兴趣头作为已验证的实验分支保留，不因模型更复杂而成为默认。

数据管线、时间切分、ItemCF 索引工程、CTR/排序对照、新版双塔的训练/导出/精确检索，以及命令行演示构成项目闭环。没有增加搜索双通道、logQ、完整 DIN、新精排或新版 ANN。

## 2. 最后一轮双塔真实结果

主窗口训练 2860013 次推荐正点击，951625 个训练点击物品；开发验证 8495 位用户、354626 次正点击。两组共同使用 ID/属性、相同投影宽度与批内对比目标，历史组增加此前完整自然日的最近 30 条去重推荐点击均值。每组种子 2026/2027/2028。

| 配置 | 纯双塔 Recall@1000 | 融合 Recall@2000 | 融合 Top20 观察命中 | 用户周期 NDCG@20 |
| --- | ---: | ---: | ---: | ---: |
| 原热门＋ItemCF RRF | — | 9.7700% | 1745 | 0.014512 |
| 加属性双塔，三种子均值 | 1.2954% | 9.0079% | 1716 | 0.014349 |
| 加属性＋历史双塔，三种子均值 | 1.7866% | 9.3326% | 1746 | 0.014687 |

历史提高了双塔自身的纯召回，不能把这解释为超过现有强召回链路。固定总预算时，历史双塔三个种子的候选命中增量为 −1402 / −1709 / −1542；Top20 为 +2 / −17 / +18。平均 Top20 只增加一次、种子方向不一致；NDCG 有小幅开发增量，但不能据此忽略候选覆盖下降或宣称线上提升。

例如种子 2026 的历史双塔在原池外覆盖 4066 次点击；融合实际引入 3341 次，却挤掉 4743 次，净减少 1402 次。新路有互补候选，不代表直接等权融合后一定有净收益。这一轮不再围绕结果追加融合超参搜索。

较早窗口严格截止 2023-05-28：2249027 次训练正点击、805466 个物品；评测 12443 用户、610986 次点击。两组均使用预设种子 2026：

| 配置 | 纯双塔 Recall@1000 | 融合命中@2000 | 融合命中@20 | 周期 NDCG@20 |
| --- | ---: | ---: | ---: | ---: |
| 原热门＋ItemCF RRF | — | 73283 | 2796 | 0.013866 |
| 加属性双塔 | 1.8063% | 69692 | 2804 | 0.013950 |
| 加属性＋历史双塔 | 2.7840% | 72848 | 2879 | 0.014339 |

历史组在较早日期的头部指标有增量，但候选仍减少 435 次命中。这是回溯复核，不是新的独立盲测，也不证明跨日期多种子稳定性。结合主窗口，不通过预先固定的“候选净增量且 Top20 不退化”采用条件；保留旧 RRF，不再追调融合参数。

## 3. 训练是否被认真验收

不是固定训练三轮就宣告完成。每轮记录在线训练损失、固定 16384 事件 probe、固定 256 开发用户的全库精确 Recall@1000，按召回选最佳轮、平台降 LR 与早停；保存两优化器、RNG、数据顺序及最近完整轮状态。

- 主窗口属性组最佳轮 1/2/2，停止轮 5/6/6。
- 主窗口历史组最佳轮 3/3/3，停止轮 7/7/7。
- 较早属性/历史组最佳轮均为 2，均在第 6 轮停止。
- 8 个模型均因验证平台早停，无最大轮数预算停止。训练 probe 继续改善而验证召回回落，属于开发泛化平台/过拟合信号，不宣称数学上的全局收敛。

PAD 固定零、缺失作者归 PAD、UNK 可学习；最佳检查点保存实际输入支持，未训练 token 回退 UNK，不用随机 embedding 推理。日级历史和静态属性的假设均在配置/元数据中记录。

## 4. 前几轮优化留下了什么结论

1. **召回工程有可复核收益。** 热门＋改进 ItemCF 在相同开发用户和 2000 候选预算下，Recall 从近期热门的 9.4229% 到 9.7700%；索引实现分块构图、邻居截断、内存映射、版本和摘要校验。
2. **表示学习改善了曝光预测。** 全量曝光下，匹配训练协议的 ID/属性到 caption 内容增强，三种子 AUC 为 0.719850→0.722349，GAUC 为 0.619901→0.623011。不是预训练中文向量；caption 是匿名词 ID。
3. **曝光预测与候选列表表现不相同。** 内容模型直排周期点击覆盖没有超过 RRF；冻结兴趣头没有额外收益。不能据此否定完整端到端 DIN，但本项目不继续扩展该分支。
4. **修正训练工程能改善评估，却不保证替换强基线。** 补齐选轮/早停后，数值 R 直排均值 536→670.33，仍低于 RRF 1745。pairwise 对匹配继续 BCE 有增量，但未超过已有最佳权重，不采用。

数值 R 与内容模型的架构/LR 不完全相同，不把二者差值归为纯 embedding 因果增益。详细证据分别见 [收敛补验](RANKING_CONVERGENCE.md)、[pairwise 微调](EXACT_PAIR_FINETUNE.md)、[表示学习](REPRESENTATION_EXPERIMENT.md)。

## 5. 工程交付与边界

- 环境：Python 3.12.14 / PyTorch 2.8.0+cpu；`pip check` 通过。
- 完整回归：142 项测试通过，包括完整轮恢复、PAD/UNK、逐次 dropout 去重等价、检索与独立重算夹具、重复运行锁和公开摘要校验。
- 新版向量索引：物品与用户向量均为冻结快照，物品库约 95 万，主窗口数组约 245 MiB；分块精确点积，不是 ANN/FAISS，也不是实时用户编码服务。
- 延迟仅为 8 位抽样用户的热进程本地精确检索，不含网络/并发 SLA；部分测量与训练并行，不能当专门性能基准或生产 QPS。
- 原始数据、大缓存、逐用户结果、embedding 权重与索引留本地；公开发布只含代码、报告、聚合指标与校验清单。

最终独立审计通过：两窗口全部训练目标逐行 SQL 对齐、全部物品属性核验；8 个模型最佳轮/优化器/导出核验；75856 个用户—模型组合的列表指标独立重算。评测另完成 64 次实际 RRF 执行器抽样重放，v1 原 32 个冻结资产均不变。

可提交的聚合交付位于 [experiments/closure_20261022](../experiments/closure_20261022/summary.json)，包含结果、曲线、审计、测试和冻结清单；完整数据/权重/索引仍在本地。冻结校验同时覆盖本地 SQLite、原始 ZIP、缓存与大权重。不自动推送 GitHub，不将“整理为可提交产物”称为已经线上发布。

## 6. 不应怎样解读这些指标

所有 v2 结果都是复用开发日或较早日期回溯，不是新盲测。旧 v1 测试已查看，其 [历史报告](FINAL_REPORT.md) 独立保留，不把旧成绩归给新版模型。

推荐列表是在截止点为每个用户生成一份静态列表，与次日历史点击比较；受日志曝光策略影响，不是请求级、无偏相关性或线上 CTR。主窗口训练点击物品库只覆盖约 54.60% 的验证点击，池外与库外问题要分别解释。同时间戳不等于已确认请求，批内候选不等于曝光负样本。
