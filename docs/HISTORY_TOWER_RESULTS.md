# 历史与属性双塔实验（2026-10-15）

推荐 valid，正例事件分母 354,626。三个双塔都使用推荐训练期 951,625 个被点击物品、相同的 2,410 位无训练点击用户热门兜底，以及精确 Top100；未过滤历史物品，未使用测试交互。

| 方法 | 命中@100 | 全量事件 Recall@100 | 有训练点击用户命中@100 |
| --- | ---: | ---: | ---: |
| 纯 ID 双塔 | 2,067 | 0.5829% | 651 |
| 历史双塔，属性向量置零 | 1,933 | 0.5451% | 517 |
| 历史 + 类别/类型双塔 | 2,155 | 0.6077% | 739 |
| 热门对照 | 3,320 | 0.9362% | 1,904 |

三版双塔均有 1,416 次命中来自冷用户热门兜底。有训练点击的用户组共 6,085 人、296,632 个正例事件；组合版本该组 Recall@100 为 0.2491%，仍低于同组热门的 0.6419%。

## 模型与时间约束

用户塔拼接用户 ID embedding 与历史物品塔向量均值，再投影、LayerNorm、L2 归一化。物品塔拼接物品 ID、一级类别和类型 embedding 后投影、LayerNorm、归一化。历史最多 20 个点击，保留重复事件，不做时间加权。

训练按时间构造样本历史，先为同一毫秒的整组事件生成历史，再写入该组行为，保证样本只能看到严格更早的点击；不同用户历史隔离。验证固定使用训练末尾历史，不使用验证点击更新查询。前缀历史会随目标事件变化，但仍与纯 ID 版一样把同一用户在批内的其他点击作为正例；这是本轮沿用的损失口径，后续目标兴趣变化时应单独检验。

训练参数：32 维、批大小 1024、温度 0.1、种子 2026、两轮训练，SparseAdam(lr=0.01) 更新 ID，Adam(lr=0.001) 更新其他参数。固定使用第二轮，无验证 checkpoint 筛选或超参数搜索。批内负例不等于曝光未点击，打分不作为 CTR 概率。

类别和物品类型按静态内容属性使用，数据没有属性快照时间。属性词表只在训练候选物品范围内建立，类别 0、类型 UNKNOWN 归入缺失。没有使用用户活跃等级、全时段统计、作者热度或上传时间特征。候选库仍不包含新物品，因此本次不是新物品召回实验。

## 消融解释

组合版相对 ID 版多 88 次命中，绝对增幅 0.0248 个百分点。仅历史版本没有改善，不能将增益归因于历史。属性消融保持相同架构和参数初始化形状，将类别/类型向量置零；组合版比属性置零版多 222 次命中。尚缺“有属性、无历史”的消融，所以无法断言历史在有属性条件下提供了增益。

按用户聚类、有放回重采样 2,000 次，组合版减 ID 版的 Recall 差值 95% 区间约为 [0.0023, 0.0478] 个百分点；组合版减属性置零版为 [0.0444, 0.0810] 个百分点。该结果仅为单种子验证集上的探索性比较，未做多重比较修正，不作为独立测试结论。
