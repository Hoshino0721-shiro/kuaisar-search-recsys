# 推荐验证集首轮 baseline（2026-10-15）

运行：`python -m src.baseline`。结果：`experiments/r0_p0_valid/metrics.json`。只读数据，训练集拟合、验证集评测，未查询测试交互。数据清单和脚本 SHA256 已记录。无超参数扫描；物品 CTR 平滑强度预设为 20。

训练 5,752,167 行，验证 725,753 行。CTR 是本数据集分布上的点击概率，不代表线上真实流量 CTR。

| 方法 | AUC | 用户 GAUC | LogLoss | Brier |
| --- | ---: | ---: | ---: | ---: |
| 训练全局点击率常数 | 0.500000 | 0.500000 | 0.693036 | 0.249944 |
| 平滑物品点击率 | 0.598490 | 0.562872 | 0.677413 | 0.242344 |

物品概率为 `(训练点击数 + 20 * 训练全局点击率) / (训练展示数 + 20)`；未知物品退化为全局概率。GAUC 按用户分组，以有效组记录数加权，排除单一标签组。概率指标使用原有验证记录，不另做负采样。精排阶段此次未计算列表 NDCG，因为推荐日志尚未定义可靠请求级候选列表。

## 热门召回

按训练正点击事件数降序、同分 item_id 升序。每个事件使用同一份 Top-K，不过滤历史。以下为事件加权命中率（每个验证点击事件有一个正物品），不是按用户去重后的宏平均 Recall。

| K | 命中正例事件 / 全量正例 | 全量 Recall | 训练已见物品正例 Recall |
| --- | --- | ---: | ---: |
| 50 | 1,817 / 354,626 | 0.5124% | 0.8461% |
| 100 | 3,320 / 354,626 | 0.9362% | 1.5461% |

推荐训练期物品库含 1,806,625 个物品；验证正例中只有 214,739 个事件的物品在该库出现。因此静态训练物品库的事件 Recall 上限为 60.5537%，不能通过增大 K 消除这一限制。

未知物品验证记录共 327,576 行，退化预测 AUC=0.5；已见物品 398,177 行，AUC=0.629387。这里的已见/未知只相对推荐训练日志，与准备阶段使用两个场景联合训练集的 cold-start 口径不同。

## 后续

1. ItemCF 与双塔使用同一验证口径，分报全量及已见物品结果。
2. 新物品候选必须限定预测时刻之前可用的物品，不能把测试期物品提前加入索引。
3. 搜索排序独立按会话评测；搜索重复事件排除造成的候选改变需要单独披露。
4. 本轮只是统计基线，尚无 LR/MLP、双塔、ANN 或延迟评测结果。
