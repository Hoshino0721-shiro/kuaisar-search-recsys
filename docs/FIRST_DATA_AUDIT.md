## 发现的问题及限制

物品特征表 item_type 少量取值为文案片段；多数为 NORMAL / AD / UNKNOW，与搜索侧 VIDEO / IMAGE_ATLAS 等枚举不同。标准 CSV 解析虽未报告行宽错误，但仍可能存在转义或语义字段错位，不能据此宣称数据干净。当前物品行数只是解析结果，不等于已验证的独立物品数。

本次只检查空字符串和缺列，不等于排除了 NULL 等缺失哨兵。精确重复、关联键覆盖、会话一致性、冷启动尚未检查。原内存版切分原型不能直接用于千万级日志，且还需适配搜索时间字段和毫秒单位。未冻结切分，未训练模型。
