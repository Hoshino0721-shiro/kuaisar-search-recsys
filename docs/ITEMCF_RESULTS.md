# ItemCF 验证实验（2026-10-15）

命令：`python -m src.itemcf`。记录：`experiments/r1_itemcf_valid/metrics.json`。

## 固定协议

- 仅推荐 train 构建用户历史和共现；每用户最近 30 个不同点击物品，二值用户-物品矩阵。
- 余弦相似度，对角线置零，累加用户历史各物品的相似度；未截断邻居列表。以稀疏乘法计算，不构造全量物品相似矩阵。
- 同分按 item_id 升序。未过滤历史物品，保持与 R0 的重复交互口径一致。
- valid 共 8,495 个用户，354,626 个正例事件，其中 214,739 个事件的物品出现于推荐 train。指标为事件加权 Recall，并非用户宏平均。
- 对照热门榜在本次重新计算，命中数与上轮 R0 完全一致。没有使用 test，没有参数搜索。

## 实际结果

| 方法 | Recall@50 | Recall@100 | 已见物品正例 Recall@100 |
| --- | ---: | ---: | ---: |
| 热门 | 0.5124% | 0.9362% | 1.5461% |
| ItemCF（最近 30 点击） | 0.0333% | 0.1066% | 0.1760% |
| ItemCF 不足 100 时热门补齐 | 0.2741% | 0.5155% | 0.8513% |

ItemCF 有候选的用户占 70.1589%，平均返回 67.03 个候选，所有用户 Top100 合计覆盖 208,744 个不同物品。该“用户覆盖率”包含没有验证点击的用户，不等于正例命中用户比例。补齐策略不改变已经返回的 ItemCF 候选顺序，不是学习式融合。

原实现本机逐用户稀疏计算加排序 P50=3.942ms、P95=11.405ms、P99=15.018ms。优化稀疏转置缓存和 Top-K 后，复跑命中数完全一致，P50=0.389ms、P95=1.430ms、P99=1.962ms。不含拟合、SQL 读取和线上网络开销，也不是服务 QPS 或生产延迟。新旧计时为单次测量，缺少重复测量与环境控制，不能当作严谨的系统加速倍数。

## 结论与限制

当前实现明显弱于热门召回，不能写成性能提升。历史截断后的共现物品库只有 246,384 个物品，而推荐训练日志共有 1,806,625 个物品；这是覆盖限制的证据，但尚未证明它是性能低的唯一原因。共同用户噪声、重复消费倾向及截断策略需要消融验证。

下一步优先比较“全训练历史构建共现、近期历史作为查询”与当前双重截断策略，增加最小共现支持度和邻居 TopN，并报告候选库对验证正例的覆盖上限。随后接双塔；沿用同一验证集、清洗版本和全量/已见物品两种分母。正式测试集保留至配置冻结。

新增稀疏实现与显式小矩阵余弦相似度一致性测试、排序并列测试；全部 15 项测试通过。脚本、数据 manifest 摘要和 NumPy/SciPy 版本保存在实验 JSON 中。

## 全历史共现消融

命令：`python -m src.itemcf --full-cooccurrence`；记录：`experiments/r1_itemcf_full_valid/metrics.json`。共现统计改为全部训练点击，查询保持最近 30 个不同点击，其他评测条件一致。

| 方法 | Recall@50 | Recall@100 | 已见物品正例 Recall@100 |
| --- | ---: | ---: | ---: |
| 截断共现 ItemCF | 0.0333% | 0.1066% | 0.1760% |
| 全历史共现 ItemCF | 0.1097% | 0.2642% | 0.4363% |
| 全历史 ItemCF + 热门补齐 | 0.3471% | 0.6663% | 1.1004% |
| 热门 | 0.5124% | 0.9362% | 1.5461% |

共现库由 246,384 扩至 951,625 个物品。其对全量验证正例事件的覆盖上限由 40.1561% 增至 54.6037%，这里仅指物品存在于共现库的必要条件，不保证用户与物品在共现图中可达，也不保证评分能将其排入 Top-K。

全历史版本 Recall@100 是截断版约 2.48 倍，仍弱于热门；支持“截断损失覆盖”的判断，不足以证明扩大历史已经解决评分问题。两种版本都没有过滤训练消费过的物品，后续过滤策略必须另立可比较实验。

全历史版本候选用户覆盖 70.7475%，平均 70.31 个候选，Top100 合计覆盖 357,066 个物品。本机 P95=24.747ms，完整实验耗时约 83.42 秒。截断版优化复跑耗时约 15.68 秒。

新增向量化 Top-K 与参考排名一致性测试，全部 16 项测试通过。截断版的 118/378 个纯 ItemCF 命中和 972/1,828 个热门补齐命中均与优化前一致；热门对照的 1,817/3,320 个命中与 R0 一致。两次消融使用同一代码和数据清单摘要。

已确认本地 PyTorch CUDA 可执行，设备为 RTX 5070，约 11.94 GiB 显存。下一阶段建立双塔训练和精确向量检索基线，先在 train 物品库上比较，再接 ANN。该设备检查不代表已完成双塔模型训练。
