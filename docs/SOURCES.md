# 数据来源

- KuaiSAR 官方主页：https://kuaisar.github.io/
- KuaiSAR 官方详细字段说明：https://kuaisar.github.io/detailed_statistics.html
- Zenodo 数据记录：https://zenodo.org/records/8181109
- KuaiSAR 论文：https://arxiv.org/abs/2306.07705

官方数据记录包含 `KuaiSAR.zip`（KuaiSAR-small）和 `KuaiSAR_v2.zip`（完整 KuaiSAR）两个文件。项目当前优先使用小版本完成链路审计和 baseline，必要时再切换完整版本。
