# 时效与召回特征 2×2 对照

2026-10-22。用户授权执行四组实验。先固定协议，随后完成真实训练、同池全量评测及独立审计；结果见下半部分。不修改默认推荐，不使用 test 标签，不自动推送 GitHub。

## 固定协议

四组为 base、T（时效）、R（召回）、TR（两者）。统一原始向量 Cross 两层 + Deep 64→32，输入总宽度 34；关闭的组在训练样本标准化后置零。所有组模型参数量、初始化规则、样本、批次及训练预算一致。因为统一宽度大于旧 20 维，本轮 base 是容量匹配的新基线，不与旧权重逐位等同。

相同种子 2026 无放回均匀抽取 100 万真实训练曝光，三个训练种子 2026/2027/2028，BCE、Adam lr=0.001、weight_decay=1e-5、batch4096、固定最后第 5 轮。每轮保留曝光曲线，但不据验证分数换 epoch。12 个模型全部报告，不事后挑最好种子。

保留原 20 维数值输入（包括已有类别匹配和搜索统计）。新增时效 8 维：前 1/3 完整日曝光和点击的 log1p、先验平滑 CTR、昨日点击占累计比例、昨日与此前两日平均点击的 log 增长。没有使用验证日反馈，也不将首次观测日期叫作真实发布时间。

召回 6 维：近期热门/CF 命中标志、各自 60/(60+rank)、log1p(CF score)、两路缩放 RRF 之和。每路取量严格为近期热门2000、CF1000；未命中某路是缺失特征，不是 click=0 标签。无历史用户 CF 为空。累计热门保持关闭。

训练日的热门、共现图、最近30个去重种子仅使用该日零点之前训练点击。每个训练日单独建实际 Top300、共同用户至少2、alpha0.25 的 ItemCF 索引；目标当天点击在提取完全部特征后才更新统计。不能用最终索引配“更早用户历史”冒充过去图。首日空图和空近期热门是合法状态。

验证全部使用 5/29 零点训练末快照。物品库、8495用户和每人2000候选与已发布优化召回一致，候选 JSONL SHA256 必须匹配 `99abfbdb6e69d33264ae2b5c2a00031cf4edd8f984ef7e4c98054e861a73346e`。

## 验收

主对照为同池直接精排 Top20 的用户周期 NDCG 和点击事件 Recall，同时报告真实曝光 AUC、用户 GAUC、LogLoss、Brier。全部模型使用同一 LR 粗排400、精排80、重排20预算，再做全种子级联与关闭重排对照，不只检查最好模型。

保留 RRF 原序和近期热门 Top20。按每用户先平均三个种子再探索性 bootstrap，比较 T−base、R−base、TR−base 及交互差值。记录训练/验证曝光中路由匹配覆盖率，不能只筛有召回命中的正例训练。验证日已经用于多轮开发，不称为独立盲测，bootstrap不证明时间泛化。

审计包括当前日/未来点击不改变历史索引的合成测试、特征 mask 隔离、真实日级计数 SQL 重放、索引 cutoff/config/摘要校验、首日空历史、全部候选摘要/命中与逐用户加总。原数值特征、数据及默认权重不覆盖。

### 效果判断

- T 相对 base：直排命中增加25.12%、NDCG增加18.81%；级联命中增加15.45%。三个种子的直排和级联命中方向均为正，支持本窗口内时效信息有增量。
- R 相对 base：直排命中增加44.14%、NDCG增加52.54%；级联命中增加24.82%、NDCG增加36.53%。三个种子方向均为正，说明已有召回名次/匹配信息值得进入精排，而不需要先换网络或损失。
- TR 的平均直排命中512.33与R的512.67接近，NDCG低于R；级联命中508.00与R的506.33接近。组合未显示全面胜出，且种子波动更大。不能据此断定特征冗余为唯一原因，优化交互和样本差异仍待验证。
- 四组曝光AUC约0.7127，GAUC与LogLoss无统一改善。R在已曝光候选交集上的AUC也未提升，显示本轮收益主要体现为当前固定候选头部的日志点击覆盖，而非全面改善点击预测。
- R的直排事件Recall约0.1446%，相对base只增加0.0443个百分点；级联Recall相对增加0.0284个百分点。高相对百分比来自较弱基线，不能隐藏与RRF/近期热门的差距。

### 本轮采用结论

保留R作为后续候选精排基线，T保留为有开发增量的对照；不因TR特征更多就选它。默认入口与权重不切换。下一步优先在滚动时间窗口复核，再检验保留召回先验的有限调整或排序目标；不继续在同一验证日扩大特征/权重搜索。

全种子直排和级联完成后，独立审计脚本重载全部12个模型、核对逐用户汇总，并在16位抽样用户上通过原Cascade执行器完成192次用户—模型重放，全部通过。最终审计见 [audit.json](../experiments/temporal_route_valid_20261022/audit.json)，完整聚合指标和曲线见 [实验目录](../experiments/temporal_route_valid_20261022)。
