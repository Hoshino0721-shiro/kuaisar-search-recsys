# 剩余问题

当前实验已经结束。以下问题保留为后续研究方向，已完成结果见 [实验总结](PROJECT_FINAL_V2.md)。

## 排序目标与分组

曝光BCE、候选列表覆盖和请求级排序对应不同任务。现有日志可以按用户与完全相同时间戳构造近似分组，但没有经过确认的request/slate ID。已有pairwise对照相对继续BCE有增量，仍未超过已有最佳权重。

进一步比较LambdaRank/LambdaLoss前，需要固定训练分组、采样和评测口径，避免把样本改变当作损失函数收益。

## 召回与排序的一致性

多路召回的独有命中会被固定候选预算抵消。当前双塔虽提供互补候选，等权RRF仍挤出了更多已有命中。可研究召回先验上的有限调整或粗精排蒸馏，并分别报告新增、丢失和最终TopK变化。

教师软分数与实际点击标签应分别保存。训练期图和召回名次必须来自目标时刻之前，不能使用训练末图回填早期样本。

## 兴趣与内容

已完成匿名caption表示、冻结表示上的均值/候选相关推荐兴趣头，以及属性/历史双塔。冻结兴趣头没有得到额外收益，其结果仅约束本轮设置。

搜索词编码、搜索与推荐双通道兴趣、端到端DIN仍未完成。搜索和caption中的词ID是匿名整数，不能直接当中文文本送入预训练模型。缺少可靠曝光概率时，热门度重加权也不能称为IPS无偏学习。

## 历史字段问题

早期增强缓存把raw author 0作为普通作者处理；新表示实验和双塔已将其映射为PAD，并检查实际训练输入覆盖。旧报告保留原值。后续训练同时改变了数据量、表示和优化流程，因此不能将收益单独归给PAD修正。
