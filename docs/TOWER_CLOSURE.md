## 两组而非继续扩展模型

属性双塔：用户 ID；物品 ID、作者、类目、类型。历史双塔仅增加推荐历史物品塔向量均值。输出 64 维单位向量，点积检索。不新增搜索、caption、logQ、复杂序列或新精排。

主窗口每组种子 2026/2027/2028；较早窗口两组各固定种子 2026，不能当作跨日期多种子稳定性证明。主窗口训练 2860013 条正点击，951625 个训练点击物品；较早窗口训练 2249027 条，805466 个物品。

用户/物品 ID dropout 0.1；作者原始 0/缺失映射 PAD。检查点保存实际训练输入支持 mask，推理未使用过的 token 回退零初始化、可学习 UNK。历史计算在逐次 ID dropout 之后按“原物品＋dropout 状态”去重投影，保留每次独立 dropout，梯度与未去重实现有数值对照测试。

## 固定训练与选轮协议

`configs/tower_closure.json`：CPU、四线程、batch512，dense Adam / SparseAdam 初始 LR 均为 0.001。批内唯一目标类别的对比 softmax，两组使用相同的推荐/搜索因果历史来屏蔽已知正例，当前目标保留；差别仅在是否把推荐历史输入用户塔。其他目标只是采样对比对象，不是观测负曝光。

每轮记录在线训练对比损失和固定 16384 事件 probe。**选轮使用固定 256 位开发用户的全训练点击库精确 Recall@1000**，不是批内 accuracy。各组用相同选择用户；记录选择用户与其余开发用户的最终指标，后者也不是新盲测。

最少 5 / 最多 16 轮；连续 2 轮无超过 1e-5 的 Recall 改善将两种 LR 减半；连续 4 轮无有意义改善、至少两次降 LR 后早停。最佳轮为最高 Recall，完全相同时保留较早轮；达到最大轮数明确标记预算结束，不称已经收敛。保存最佳和最近完整轮权重、两优化器、RNG、顺序生成器和调度计数，仅支持完整轮恢复。

## 验证与采纳标准

主窗口：2023-05-29，当日反馈不更新 query；回溯窗口：2023-05-28，训练截止严格提前一天，图和物品库均使用同一前缀。

共同控制为近期热门 Top2000＋支持度门槛 2 的 ItemCF Top1000、邻居 300、关闭查询时间衰减。新增双塔取 Top1000，三路等权 RRF，**总候选仍为 2000，输出仍为 20**。报告纯双塔 Recall@100/1000、物品库可达正例、query 支持分组、融合得到与丢失的点击、Top20、周期 NDCG 和索引/检索成本。

历史双塔为预设主配置，不在全量评测之后从两组中挑赢家。只有三个主窗口种子和较早固定种子均增加 Recall@2000 且 Top20 观察命中不下降，才进入采用讨论；否则保留原 RRF。即使通过，最终仍需审计，不由训练脚本自动改默认配置。属性组只是对照。

所有列表指标受日志曝光策略与静态快照任务限制，不支持线上 CTR、生产 QPS 或无偏相关性结论。单用户延迟仅 8 个抽样用户、热进程本地 CPU；并行训练期间的测量还存在资源竞争，不能作为专门性能基准。
