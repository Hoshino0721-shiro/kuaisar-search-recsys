# 收尾执行计划

完成标准：数据版本固定，召回/精排/重排闭环可以执行，验证集选型、测试集最终评测，结论可回溯到配置和结果文件。

1. CTR 特征按训练日期滚动构造，样本只使用前一天及更早的统计；验证与测试固定训练截止统计。搜索短期通道使用训练截止前一个自然日的点击类别偏好。
2. LR、非线性排序和搜索通道消融在验证集比较；搜索信号有效性按真实结果报告。
3. 全时热门、近期热门、双塔候选融合，比较覆盖与 Recall。选择规则、精排参数和重排参数在最终测试前冻结。
4. 在冻结配置下评测测试集，分开记录原始曝光 CTR 评测、全库候选召回和重排的质量/成本，避免给未曝光候选编造负标签。
5. 保存模型、配置、校验值、候选、实验表、运行命令、限制和面试/简历材料。对未达到验收的扩展明确标记，不以假数字补全。
