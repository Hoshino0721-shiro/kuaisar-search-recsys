# 全量 embedding / 内容 / 兴趣实验（2026-10-22）

用户同意升级表示层。本轮固定真实曝光 BCE，不同时更换配对损失；旧统计特征、召回特征与默认 RRF 保留，不读最终测试标签、不自动推送 GitHub。

工程修正：第一版模型在 `models/` / `interest/`，只用于排查，不能作为最终效果证据。其词表包括训练历史中的 ID，但目标表示训练不一定更新过这些 ID 的向量。新 `representation_dcn_v2` 为每张 embedding 表在训练前向记录实际使用过的 token（ID dropout 后），最佳检查点同时保存覆盖 mask；推理和冻结导出将未使用过的 token 回退至 UNK。PAD 固定零，UNK 可学习，未拟合时保持零初始化。新训练使用 `models_safe/` / `interest_safe/`，不覆盖旧权重；原源码字节快照保存在 `source_v1/`。

## 预先固定的分阶段对照

1. **ID/属性**：用户 8 维，物品 ID 16 维、作者/类目各 8 维；与原 20+6 维有效数值输入共同训练 DCN。
2. **内容增强**：增加匿名 caption 前 8 个 token 的 8 维可学习词向量及 masked mean。物品 ID、属性和内容拼接后投影到 16 维。两组保留相同分配宽度与初始化，内容关闭组输入该位置为零。
3. **历史均值对照 / 候选相关兴趣头**：用已训练内容编码器产生冻结物品向量，在同一内容模型分数上学习零初始化残差；分别对历史向量做均值和 DIN-inspired 候选相关激活。两组同宽、相同初始化与预算。**这是冻结表示的分阶段兴趣实验，不冒称完整 DIN 论文复现或全端到端编码器微调。** 此约束用于本机 CPU 下先隔离历史聚合机制，再考虑联合微调。

所有真实训练都使用全 5752167 条推荐曝光，种子 2026/2027/2028。先学目标物品表示，再进行冻结表示兴趣头对照，不使用验证反馈更新历史。

目标表示训练：Adam + SparseAdam，初始 LR 0.0005，batch4096，最少 5 / 最多 16 轮；完整验证 LogLoss 选最佳轮，每 2 轮无超过 1e-5 改善时学习率减半，至少两次降 LR 且连续 4 轮无有意义改善后早停。每轮记录固定训练 probe、完整验证 LogLoss/AUC/GAUC/Brier/同时间戳 NDCG；保存最佳及最近完整轮 Adam、SparseAdam、RNG、历史与协议。预算上限不冒充收敛。

表中 PAD=0、UNK=1。作者原始 0 和缺失类目归 PAD；未知但非缺失属性归 UNK。匿名词原始 ID 0 不是自动 PAD，而是独立重编码。用户/物品 ID 训练时有固定 0.1 的整 ID UNK dropout，两组相同；不将随机未训练 embedding 带入验证。

## 新缓存与覆盖

全量推荐曝光与先前完成的逐行 SQL 时间重放缓存对齐。历史按前一完整北京时间自然日冻结：推荐取此前最近 10 个点击（保留重复），搜索取前一日视频/图集点击；同日反馈不可见。并列时间按 timestamp/item/id 排序，只保证确定性，不宣称反馈到达顺序。

训练词表拟合实际训练目标及其因果历史输入，按目标上下文使用次数计数，频次至少 5；caption 词表按此频次截前 60000 词，静态属性/匿名文本允许编码冷 ID。没有验证或 query 反馈拟合词表；静态属性/文本没有历史版本时间，仅按静态元信息假设使用。

缓存 `artifacts/representation_20261022/cache`，62233 个用户—日期上下文。用户/物品/作者/类目/词表大小（含 PAD/UNK）为 21772 / 368834 / 238118 / 38 / 60002。17445 条训练曝光的作者缺失/原始 0 被正确映射，不改动旧增强缓存。

| 冻结历史 | ID UNK 比例 | 至少含一个已知 caption 词的物品比例 |
| --- | ---: | ---: |
| 推荐 | 25.88% | 99.93% |

这些是非 PAD 历史物品的覆盖，不是平均词覆盖、完整语义理解或模型效果。词向量从本数据训练，不用中文 BERT 解释匿名整数。搜索历史仍先记录覆盖，首批兴趣头仅用推荐历史，搜索通道留作后续明确消融。

覆盖表统计的是全用户冻结查询快照，不仅限于 8495 个验证用户。对实际最佳内容检查点再核验，推荐历史约 26.07%、搜索历史约 94.78% 的 ID 没有有效训练输入支持，需要回退；有支持的 caption 词覆盖仍约 99.93% / 99.74%。这正说明“在词表内”与“检查点已使用过”不能混淆。该检查仅证明输入支持，不保证语义质量或未知物品排序效果。

## 目标表示结果（仅使用 safe v2）

全 5752167 条曝光、三个种子。ID/属性最佳轮次 1/2/1，内容组 1/1/1，之后训练损失继续下降而验证损失上升，均在 5–6 轮完成平台验收，没有因 16 轮上限结束。数值基线来自上一轮已验证的全量 R 模型；它的宽度/LR/优化器配置不同，所以下表对数值基线的差值是开发对照，**不是完全隔离训练/容量因素后的纯 embedding 因果增益**。内容与 ID/属性之间则是同宽、同数据、同损失与训练协议的输入对照。

| 配置 | AUC | LogLoss | 用户 GAUC | 同时间戳组 NDCG@20 | 同池直排命中 | 周期 NDCG@20 | 完整级联命中 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 原数值 R | 0.713703 | 0.618742 | 0.607098 | 0.817604 | 670.33 | 0.004831 | 699.33 |
| ID/作者/类目 embedding | 0.719850 | 0.615269 | 0.619901 | 0.823067 | 581.33 | 0.004614 | 541.33 |
| 再加入 caption embedding | 0.722349 | 0.613342 | 0.623011 | 0.823966 | 535.33 | 0.004315 | 525.67 |
| RRF 原顺序 | — | — | — | — | 1745 | 0.014512 | — |

同时间戳指标是混合正负的曝光行组，不是已确认的请求 NDCG。周期指标是固定截止快照的观察日志覆盖，受历史曝光策略影响；不能将更高 AUC 换算成线上 CTR 提升，也不能将周期覆盖下降等同为无偏用户相关性下降。

内容组相对 ID/属性组，三种子的 AUC 均提高，但直排命中分别 703→661、372→329、669→616，三个种子均降低。表明更好的曝光分类能力并没有自动解决完整候选排序目标/分布问题，当前不支持更换默认 RRF。

两种目标模型均真正训练了可学习的稀疏 embedding；作者/类目各 8 维、用户 8 维、物品 16 维、caption 词 8 维，最终物品表示 16 维。它们用于排序特征，不是训练好可直接点积检索的双塔，也不是预训练中文文本向量。

## 历史兴趣结果与最终验收

三个种子的均值池化、DIN-inspired 候选相关注意力残差均完成 5 轮训练、两次学习率下降及平台验收。所有最优选择均为第 0 轮，即冻结内容模型本身；第 1–5 轮没有超过初始化的验证 LogLoss。因此最终曝光及全部逐用户候选/级联指标与内容模型完全一致，不声称“均值与 DIN 学得一样好”，也不将回退后的内容收益归给注意力。

这是一项冻结编码器、前一完整日历史、最近 10 条推荐点击的特定实验，不能据此否定端到端 DIN、搜索兴趣或其他序列模型。注意力分支本轮未获得可采用增量，默认配置没有切换。

探索性用户 bootstrap（先平均三个种子、1000 次采样）：内容−ID/属性的周期 NDCG 差为 −0.000299，95% 区间 [−0.000453, −0.000155]；内容−原数值 R 为 −0.000517，区间 [−0.000879, −0.000148]。这不等于跨种子或线上显著性，没有多重比较校正或独立时间窗口保证。与旧数值组比较还存在训练协议/容量差异，不能做纯单因素归因。

最终 `model_audit.json` 已通过：12 个 safe 模型的最佳权重、实际 Adam/SparseAdam 更新次数、输入覆盖 mask 与 UNK 回退、推理不更新 mask、完整验证 AUC/GAUC/LogLoss/Brier、各模型 108305 个混合时间戳组 NDCG、全用户直排指标重算及级联合计全部核验；96 次真实 Cascade 抽样重放通过，32 个旧冻结资产摘要不变。数据审计与 134 项测试通过。

最终汇总 `results_safe.json`、曲线 `curves_safe.html`、12 模型最佳/最近检查点、全量评测分数和逐用户指标均在 `artifacts/representation_20261022`。`models/`、`interest/`、`evaluation_target/` 为保留的第一版排查产物，不混入最终汇总。最终源码版本与审计摘要核对一致，不自动提交或推送 GitHub。

结论：已实现并真实训练可学习 embedding，内容信息对同协议的曝光预测有稳定开发增量；完整候选的周期点击覆盖仍未超过既有方案，冻结兴趣头也无新增收益。保留内容模型作为更强的曝光预测实验基线，推荐服务仍使用 RRF。
