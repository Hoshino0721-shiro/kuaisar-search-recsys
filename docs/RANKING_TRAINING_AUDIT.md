# 第三轮排查：训练缓存、抽样与已有训练对照

本轮继续做诊断，不修改特征生成器、模型结构、权重或默认排序配置；不访问最终测试标签，也不覆盖任何缓存。

## 1. 575 万条训练记录逐日重放通过

读取 SQLite 中明确属于 train 的推荐和搜索记录，在内存里从空计数器重建 2023-05-22 至 2023-05-28 的全部训练日。
每天先计算并核对所有样本特征，完成后才更新当天推荐统计与搜索统计，避免在审计本身中引入当天标签。

同时通过：

- 每日用户、物品、点击标签与训练缓存逐项完全一致。
- 每日开始时，重放状态的总曝光与总点击等于独立 SQL 查询的严格此前统计。
- 每日确定性抽样的用户/物品历史曝光与点击计数，等于独立 SQL 的此前计数。
- 最终 12 个状态字段（含类别表、各级计数、搜索状态）与保存的训练末快照全部精确相同。
- LR、DCN 的 100 万条样本索引均能由保存的 seed 精确重建。
- 在这些实际训练样本上重新计算的 mean/std 与两个 checkpoint 的标准化参数完全相同，最大误差均为 0。

因此没有发现缓存错位、标签串行、当天记录提前更新、末状态不一致或 scaler 错用这几类实现问题。
边界：重放复用了原特征公式和已有静态类别映射，所以它不是对所有公式语义、属性时间可用性和原始数据清洗正确性的独立证明。

## 2. 现有训练结果不支持“明显过拟合”这一解释

固定选中的 DCN checkpoint，对真正参与拟合的 100 万条记录、同训练窗口未被抽中的 475 万条记录和验证曝光分别评分：

| 数据 | 行数 | AUC | LogLoss |
| --- | ---: | ---: | ---: |
| 实际拟合样本 | 1000000 | 0.701279 | 0.626637 |
| 同训练窗口未参与拟合记录 | 4752167 | 0.701652 | 0.626439 |
| 时间后移的验证曝光 | 725753 | 0.712655 | 0.619825 |

训练样本没有明显优于同窗口未抽中样本，因此当前没有训练集记忆导致严重泛化崩溃的证据。后移验证窗口更好也不证明时间泛化更强，不同窗口的分布与难度不同。
这个对照不能排除欠拟合、训练预算不足或更好的优化参数；本轮没有因此调参或重新训练。

## 3. 原有模型对照：更换 DCN 架构没有明显突破

以下均是相同特征缓存与同一验证窗口；已确认 V1 与本轮 DCN 的训练样本索引完全相同，都是 100 万行：

| 模型 | 验证 AUC | 用户 GAUC | LogLoss |
| --- | ---: | ---: | ---: |
| 原普通 MLP | 0.712720 | 0.605186 | 0.619851 |
| 原门控 MLP | 0.712799 | 0.605586 | 0.619644 |
| 本轮 DCN | 0.712655 | 0.605471 | 0.619825 |

三者结果非常接近，支持“当前输入与训练任务下，换网络的边际收益较小”。它不是严格的架构因果实验：旧 MLP 与新 DCN 的设备、正则和训练细节并未全部控制一致，也没有重复种子或显著性检验。
不能据此断言 DCN、MLP 或 DIN 存在固定优劣，更不能把以上验证指标与 V1 最终测试指标混用。

## 4. 搜索收益弱已有一个重训层面的历史旁证

原有 HGB 实验分为推荐特征 16 列和推荐+搜索特征 20 列，两模型训练参数完全一致、使用同一批训练样本：

| HGB 输入 | AUC | 用户 GAUC | LogLoss |
| --- | ---: | ---: | ---: |
| 推荐统计 16 列 | 0.711325 | 0.603784 | 0.622827 |
| 推荐+搜索 20 列 | 0.711364 | 0.603787 | 0.622805 |

AUC 仅增加约 0.000040，用户 GAUC 增加约 0.000003，LogLoss 改善约 0.000022。
已重载两个本地 HGB 权重，在确定性抽样的 4096 条验证记录上重新预测，与保存预测最大误差均为 2.22e-16，说明不是只比较文档中未核对的数字。

这一历史重训对照与上一轮搜索屏蔽结果方向一致：**现有前一日类别级搜索统计尚未显示明显收益**。但它仍不能区分时效不足、类别表达过粗、信息冗余与模型学习不足分别贡献多少；HGB 的结论也不能直接替代 DCN 的同结构重训消融。

## 当前归因收敛到哪里

1. 前两轮的目标错位和历史曝光覆盖差异有直接对照证据，仍应先明确评测任务。
2. 训练缓存与 scaler 这条链路已通过全量重放，继续盲查同类错位问题的优先级下降。
3. 没有发现严重过拟合证据；换 DCN 也没有带来明显收益。单纯加层、加轮次尚不是已证明的解法。
4. 下一步应转向固定口径的、时间受控的重训消融，验证新增信息而非只换架构。首先区分候选分布适配与搜索信息增量，不把未曝光候选伪造为负例。

截至本轮，**没有定位到一个可以通过简单改一行代码就解释全部差距的错误**。已定位的证据与尚未验证的假设需保持区分。
